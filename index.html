GETTING STARTED

How to use this tool

  1. Select locations only inside Goa. Choose Pick A and click any point within the green Goa boundary, or search for a place. Repeat for Pick B. Points in the red buffer area outside Goa cannot be selected.
  2. Understand the two boundaries. The green line marks the Goa state boundary. The red dashed line marks a 5 km buffer outside Goa. The buffer is provided only to allow a road route to briefly pass beyond Goa when the road network requires it.
  3. Measure distances. Aerial distance is a straight line between A and B. Road distance follows roads and may enter the red buffer, but it must not extend beyond the 5 km buffer.
  4. Draw your own route. Intermediate points for My Route must remain inside Goa. The red buffer is not available for selecting points or drawing a student route.
  5. Remember: The buffer does not expand the learning area. Starting points, destinations and student-selected route points must all be within Goa.
